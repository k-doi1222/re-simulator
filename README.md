# 不動産投資シミュレーション

Excelで管理していた物件・銀行・仲介業者の情報を Supabase(PostgreSQL) へ移行し、
その上で動かす閲覧・シミュレーション用のアプリ。

## できること

- **物件一覧** — 判定・キーワードでの絞り込み。同じ物件の別バージョンは畳んで1物件1行で表示
- **指値シミュレーション** — 価格を動かすと実質CF・判定・積算比率・満室利回がその場で再計算
- **指値の逆算** — 「判定を △150 / ○200 / ◎250 に乗せるにはいくらまで指値すればよいか」を自動算出
- **物件情報の編集** — 全入力項目をひとつのフォームで編集して保存
- **版の比較** — 前提違い・時点違いのバージョンを横並びで比較

投資判断の計算式はすべてデータベース側の関数（`re_calc_property_analysis`）にあり、
このアプリは値を渡して結果を受け取るだけ。計算ロジックは1箇所にしかない。

## 動かし方

接続情報を `.streamlit/secrets.toml` に用意する（`secrets.toml.example` を参照）。

```bash
uv run streamlit run app.py
```

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | 入口。認証してページ遷移に渡す |
| `auth.py` | パスワードによる入口の門 |
| `db.py` | データベース接続。SELECTは5分キャッシュ |
| `theme.py` | 入力値と計算値を見分けるための色 |
| `pages/list.py` | 物件一覧 |
| `pages/detail.py` | 物件詳細・シミュレーション・編集 |

## 注意

- `.streamlit/secrets.toml` は接続情報を含むため Git に載せない（`.gitignore` 済み）
- データベースへは **Session pooler** で接続する。Direct connection は IPv6 専用のため
  IPv6非対応の回線からは繋がらない
